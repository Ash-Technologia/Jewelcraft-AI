# 💎 JewelCraft AI — Frontend

This directory contains the client web application for **JewelCraft AI**, built with **React 18**, **TypeScript**, **Three.js** (`@react-three/fiber`), **Vite**, and **Framer Motion**.

For full project details, hackathon documentation, architecture, and backend setup, please see the root [README.md](../README.md).

## Quickstart

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
